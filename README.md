# UNIX for ML

Учебный проект по работе с UNIX-инструментами для подготовки и обработки данных в рамках School 21.

В проекте данные о вакансиях Data Scientist проходят несколько этапов обработки — от получения через API до очистки, сортировки и простого анализа.

## Что было сделано

* получение данных через API с помощью `curl`;
* обработка JSON с `jq`;
* преобразование JSON в CSV;
* сортировка данных через UNIX-команды;
* очистка и преобразование строк;
* подсчёт уникальных значений;
* разделение данных на части по дате;
* объединение обработанных файлов;
* написание shell-скриптов для автоматизации обработки.

## Стек

* Bash / Shell
* `curl`
* `jq`
* `cat`
* `sort`
* `head`
* `tail`
* `sed`
* CSV / JSON

## Цель

Получить практический опыт работы с командной строкой и научиться использовать UNIX-инструменты для сбора, подготовки и предварительной обработки данных.
